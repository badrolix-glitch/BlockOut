# BlockOut
A cross-platform 3D Tetris game in retro style. Like something very familiar from our childhood, but with the addition of a third dimension.

Version 0.2.1 features quite a few changes:

A number of minor changes have been made, such as replacing the default Gadot splash screen with a custom one "drawn" by my son using AI. This release also includes a Linux version, so you won't need programs like Wine or Proton to run the game.

Version 0.2.0 features quite a few changes:

First, the speed at which pieces fall has been halved;

Second, the complexity of previously system-generated pieces has been changed. Individual pieces could occupy a 3x3x3 space, which significantly complicates the game, and these pieces have been removed. Simpler pieces, consisting of, for example, one or two cubes, have also been added.

Third, previously, when placed near a wall, a piece would lose its ability to turn. In such cases, it would automatically shift away from the wall, thus unlocking the piece's rotation.
